# Suggested Commands

- `npm test` — run the extension integration tests through `test/runTest.js`.
- `npm run lint` — run ESLint across the repository.
- `npm run package` — build a `.vsix` package with `vsce`.
- `npm run publish` — publish the extension.
- Windows shell in this repo is PowerShell; common equivalents are `Get-ChildItem` for listing files, `Select-String` for text search, `Get-Content` for file reads, and `Test-Path` for existence checks.
